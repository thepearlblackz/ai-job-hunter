# AI JOB HUNTER

AI Job Hunter is an AI-powered automation project designed to search HSE, EHS and Safety job opportunities worldwide.

## Objectives

- Search international HSE jobs automatically
- Calculate CV match percentage
- Identify missing requirements
- Rank opportunities
- Send daily Telegram notifications
