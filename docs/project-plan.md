# AI Job Hunter - Project Plan

## Goal

Build an AI agent that automatically searches HSE jobs every day and sends ranked opportunities to Telegram.

---

## Daily Workflow

1. Search jobs
2. Remove duplicates
3. Filter based on requirements
4. AI calculates match score
5. AI explains score
6. Generate report
7. Send Telegram notification

---

## Version Roadmap

V1
- Search jobs
- Telegram notification

V2
- Match percentage

V3
- Missing requirements

V4
- Ranking

V5
- Multiple job portals

V6
- 300 jobs/day
